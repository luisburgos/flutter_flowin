## 0.1.0 (2026-08-13)

Initial release of the Flowin design system.

### Features

* **foundations:** design tokens for colour, spacing, radius, borders and typography
* **theme:** `FlowinTheme.light` and `FlowinTheme.dark`, mapping tokens onto Material's `ColorScheme`, `TextTheme` and component themes, with non-Material tokens carried on a `FlowinTokens` theme extension
* **typography:** the Inter baseline scale, plus the caption styles Material has no slot for
* **icons:** the semantic icon set at every step of the size scale
* **widgets:** buttons, icon buttons, item buttons, chips, chip groups, chip view pagers, input fields, text fields, colour swatches, cards, dividers, app bars, tabs and action sheets
* **showcase:** a companion app cataloguing every foundation and component, published to GitHub Pages
